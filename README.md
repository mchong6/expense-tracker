# Obsidian Expense Tracker

Personal expense tracking app for self-use.

This app connects to financial accounts through Plaid to import transaction data for personal budgeting, spending review, and categorization.

## Privacy

See the privacy policy:

https://mchong6.github.io/expense-tracker/privacy.html

## Security note

Do not commit Plaid secrets, access tokens, account IDs, transaction data, or user financial data to this repository.
